# Glosarium Domain — Fiqih & Istilah Operasional

## Aktor

| Istilah | Arti |
|---|---|
| **Wakif** | Pemberi wakaf |
| **Nadzir** | Pengelola program wakaf yang telah terverifikasi |
| **Muzaki** | Pemberi zakat |
| **Mustahik** | Penerima zakat |
| **Pengqurban** | Pemberi/pemesan hewan qurban |
| **Amil** | Fungsi pencatat/pengelola transaksi ZIS di lapangan — di Amwal V.1 diampu role `ADMIN` atau `PETUGAS_LAPANGAN`, BUKAN role terpisah |
| **Petugas Lapangan** | Panitia yang mencatat transaksi offline & verifikasi fisik (khususnya Qurban) |
| **Mauquf 'Alaih** | Penerima manfaat akhir dari hasil pengelolaan wakaf (bisa individu/lembaga) |

## Konsep Wakaf

| Istilah | Arti |
|---|---|
| **Wakaf** | Menahan harta untuk dimanfaatkan secara berkelanjutan, pokok harta tidak boleh habis/berpindah kepemilikan |
| **Wakaf Uang** | Wakaf dalam bentuk uang tunai |
| **Wakaf Produktif** | Wakaf yang dikelola untuk menghasilkan nilai tambah (investasi/usaha), hasilnya yang disalurkan |
| **Wakaf Pokok Kekal** | Prinsip pokok dana wakaf produktif WAJIB abadi, tidak boleh berkurang |
| **Wakaf Habis Pakai** | Wakaf yang pokok dananya langsung digunakan (mis. pembangunan fisik) |
| **Ikrar Wakaf** | Pernyataan kehendak Wakif untuk mewakafkan hartanya, dituangkan dalam Akta Ikrar Wakaf (AIW) |
| **AIW (Akta Ikrar Wakaf)** | Dokumen legal formal pencatatan ikrar wakaf |
| **Nazir/Nadzir** | (lihat Aktor) |

## Konsep Zakat

| Istilah | Arti |
|---|---|
| **Zakat Fitrah** | Zakat wajib menjelang Idul Fitri, dihitung per jiwa |
| **Zakat Maal** | Zakat harta (penghasilan, emas, perusahaan, pertanian, dll) |
| **Nisab** | Batas minimum harta yang mewajibkan zakat |
| **Haul** | Syarat kepemilikan harta selama 1 tahun (untuk sebagian jenis zakat maal) |
| **Kadar** | Persentase/tarif zakat yang wajib dibayarkan |
| **Fidyah** | Kompensasi bagi yang tidak mampu berpuasa (bukan zakat, tapi sering dikelola bersamaan) |
| **Kafarat** | Denda/tebusan atas pelanggaran sumpah/puasa tertentu |
| **8 Asnaf** | Fakir, Miskin, Amil, Muallaf, Riqab, Gharimin, Fisabilillah, Ibnu Sabil — golongan penerima zakat |

## Konsep Qurban

| Istilah | Arti |
|---|---|
| **Qurban Individu** | 1 hewan (kambing/sapi utuh) untuk 1 pengqurban |
| **Qurban Kolektif** | 1 sapi dibagi hingga 7 slot/bagian pengqurban |
| **Opsi Pasrah** | Daging qurban diserahkan sepenuhnya ke panitia untuk didistribusikan |
| **Ambil Sendiri** | Pengqurban mengambil sendiri bagian dagingnya |

## Istilah Teknis-Operasional (Bukan Fiqih, tapi Sering Muncul)

| Istilah | Arti |
|---|---|
| **Non-Custodial** | Amwal tidak pernah menampung dana publik di rekening sendiri |
| **Disbursement/Split Settlement** | Skema Payment Gateway yang meneruskan dana langsung ke rekening pihak ketiga |
| **Row-Lock** | Teknik database mengunci baris data saat transaksi berlangsung untuk mencegah race condition |
